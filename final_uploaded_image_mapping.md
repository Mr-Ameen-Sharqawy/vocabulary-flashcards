# ربط الدفعة الجديدة من الصور

تمت معاينة صور الدفعة الجديدة وربطها بالمفردات التي كانت بلا صورة. تُستخدم الصور بصيغة كرتونية واضحة، ولا توجد علامة مائية ظاهرة في المعاينة.

| المفردة | الصورة المعتمدة |
|---|---|
| attention | Child examining leaf with magnifying glass |
| behavior | Child holding umbrella for friend |
| brave / stylish | Child wearing superhero cape |
| come out | Baby chick emerging from eggshell |
| face / faced | Child looking up at climbing wall |
| laugh at | Clown dancing and children laughing |
| pay for | Child buying blue balloon |
| popular | Child receiving high fives |
| run away | Puppy running away with sock |
| same | Twin teddy bears sitting side by side |
| see … up close | Child examining ladybug with magnifying glass |
| shy | Bear hiding behind tree trunk |
| stood | Child standing to show respect |
| stripes | Colorful tiger showing stripes |
| suddenly | Jack-in-the-box popping out |
| sugar cane | Sugarcane stalks in green field |
| supermarket | Child pushing shopping cart |
| surface | Polished wooden table surface |
| take the bus | Child boarding school bus |
| terrible | Burnt cake on counter |
| thick | Giant storybook beside thin notebook |

كما أضيفت صورة الأهرامات إلى بطاقة **Pyramids** نفسها، وحُسِّنت بطاقة **smile** بصورة طفل مبتسم. لم تُستخدم صورة الأهرامات لبطاقة **Upper Egypt** لأن الأهرامات تقع في الجيزة، ويجب ألا تربط البطاقة التعليمية بصورة تخالف الموقع المقصود.
